# 百景工具箱 · 使用手册

> 界面遵循极简原则不写说明文字，操作方式集中在这里。程序文件：`dist\HyakkeiTools.exe`（配置与日志在同目录 `config\`、`logs\`）。

## 基本操作

| 操作 | 方式 |
|---|---|
| 启动 | 运行 `HyakkeiTools.exe`，静默进托盘（重复运行只会唤起岛） |
| 唤起 / 收起岛 | **双击 Ctrl**（两次短击，中间不按其他键） |
| 进入模块 | 回车（当前行）、**Ctrl+1～9**、↑↓ 后回车、鼠标点击 |
| 返回列表 | `Esc` 或单击 `Alt`；列表里再单击 `Alt` 回到刚才的面板 |
| 收起岛 | 列表态 `Esc`，或点击岛外任意处 |
| 管理中心（模块开关 / 设置） | 托盘图标右键 → 管理中心 |
| 退出 | 托盘图标右键 → 退出 |

## 岛里的万能输入

在列表态直接打字：

- 模块名 → 过滤列表
- 链接（`example.com`、`https://…`）→ 「打开链接」，回车打开
- 算式（`12*8+3`）→ 「= 99」，**F6** 复制结果（岛不关），回车复制并收起
- 其他文字 → 「翻译」，回车直接出译文
- 在任何应用里**选中文字按 F6** → 岛弹出并把文字填进搜索框（选中的是链接就直接回车打开）；没选中时 F6 无反应

## F6 = 动作键

F6 只在当前场景下做一件事，进入哪个模块面板就归哪个模块；退回列表后交还给岛（复制当前行）。

## 连点器

- 目标：左键 / 右键 / 键盘键（选中「键盘」后**再点一次**捕获新键）
- 模式：连点（间隔毫秒，预设 1/5/10/50 每秒）/ 长按
- **F6** 开始 / 停止（长按模式：按一次按住，再按松开）
- 面板收起后 F6 仍然有效；`Esc` / `Alt` 退回列表即解除并停止

## 翻译

- 面板输入：停顿 0.6 秒或回车即翻译；目标语言 自动 / 中 / EN / FR，**Ctrl+1～4** 切换
- **划词**：任意应用里选中文字按 **F6** → 取词、弹岛、出译文
- **截屏翻译**：没有选中时按 **F6**（或面板「截屏」按钮）→ 拉框 → 译文卡片贴在选区旁；卡片内可切目标语言、「复制原文」（= 文字识别）、「复制译文」，空白处可拖动，`Esc` 关闭
- 服务商：默认谷歌 → 腾讯兜底；`config\settings.json` 的 `Tools.translator` 可填 `BaiduAppId` / `BaiduSecret`，或用 `Provider` 强制 `Google` / `TranSmart` / `Baidu`
- OCR 精度取决于系统语言包：设置 → 语言和区域 → 添加语言时勾选「光学字符识别」（英文 / 法文）

## 配置项（config\settings.json）

| 键 | 默认 | 说明 |
|---|---|---|
| `ModuleHotkey` | `F6` | 动作键 |
| `DoubleCtrlIntervalMs` | `400` | 双击 Ctrl 判定间隔 |
| `Theme` | `System` | 管理中心主题 `System` / `Light` / `Dark` |
| `DisabledTools` | `[]` | 停用的模块 Id |
| `Tools.<id>` | — | 各模块自己的设置 |

改配置需重启生效（主题除外）。

## 开发

- 构建：`dotnet build HyakkeiTools.slnx -c Release`
- 打包：`scripts\publish.ps1`（单文件，依赖本机 .NET 10 运行时）；`-SelfContained` 可打包运行时
- 图标：`scripts\gen-icon.ps1`
